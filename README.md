# Depilacion-Laser-Bek-ech
Cabina de depilación láser y aparatología dermoestética 
Cabina de depilación láser corporal, apto para cualquier parte del cuerpo y tono de piel, sin cicatrices ni irritación. Disminución notable de crecimiento del vello desde la tercera sesión, aclaración de zonas con oscureciomineto por rasurado contunio.
